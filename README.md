# تموينات النكهة الشامية — موقع + لوحة تحكم

مشروع متجر عرض منتجات (بدون دفع إلكتروني) مبني من:
- **صفحة لاندينق** (`index.html`) — تعرض المنتجات والآراء وبيانات المتجر، كلها تُجلب من الـ API.
- **لوحة تحكم أدمن** (`pages/admin/`) — تسجيل دخول بـ 2FA عبر الإيميل، وتحكم كامل بالمنتجات والتصنيفات والآراء وإعدادات المتجر.
- **باك إند** (`backend/`) — Node.js + Express + MySQL.

## كيف يعمل الربط بين الواجهة والباك إند؟

كل من `index.html` ولوحة الأدمن تعتمد على ملف واحد لمعرفة رابط الـ API:

```
assets/config.js
```

بعد ما تنشر الباك إند على Render، **افتح هذا الملف وغيّر الرابط** ليطابق رابط خدمة الـ API الفعلي:

```js
window.NKHAT_API_BASE = 'https://your-api-service.onrender.com/api';
```

## النشر على Render

المشروع فيه `render.yaml` يعرّف خدمتين:

1. **nkhat-frontend** — استضافة ثابتة (Static Site) لصفحة اللاندينق ولوحة الأدمن.
2. **nkhat-api** — خدمة Node.js للباك إند (المسار `backend/`).

### الخطوات
1. اربط الريبو بـ Render (New → Blueprint → اختر الريبو، هيقرأ `render.yaml` تلقائياً).
2. عبّي المتغيرات البيئية المطلوبة لخدمة `nkhat-api` من Render Dashboard → Environment (راجع `backend/.env.example` للتفاصيل الكاملة):
   - `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`, `DB_PORT`
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD`
   - `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM`
   - `CORS_ORIGINS` = رابط خدمة `nkhat-frontend` (مثال: `https://nkhat-frontend.onrender.com`)
3. بعد نشر `nkhat-api`، انسخ رابطها وحطه في `assets/config.js` (السطر `NKHAT_API_BASE`)، وارفع التعديل.
4. MySQL: Render لا يوفر MySQL مجاني — استخدم PlanetScale أو Railway وضع بيانات الاتصال في متغيرات `DB_*`.

## لوحة الأدمن

- الدخول: `/pages/admin/login.html` — إيميل + كلمة مرور، ثم رمز تحقق (2FA) يوصل على `ADMIN_EMAIL`.
- بعد الدخول تفتح `/pages/admin/admin-base-sr67.html` تلقائياً، وهي محمية (تتحقق من الجلسة، ولو ما فيه جلسة صالحة ترجعك لصفحة الدخول).
- من اللوحة تقدر تتحكم بكل شيء يظهر باللاندينق:
  - **المنتجات**: إضافة / تعديل / أرشفة / استرجاع / حذف، مع رفع صورة حقيقية.
  - **التصنيفات**: إضافة / حذف — تظهر تلقائياً كأزرار فلترة باللاندينق.
  - **الآراء**: قبول / رفض / حذف آراء العملاء المُرسلة من الموقع.
  - **إعدادات المتجر**: الاسم، الهاتف، الواتساب، العنوان، روابط السوشيال ميديا، خرائط قوقل، السجل التجاري، رخصة المتجر، نص "من نحن"، وصورة البانر.

كل تعديل من اللوحة ينعكس مباشرة على اللاندينق عند إعادة تحميل الصفحة (لأن اللاندينق تجلب البيانات من نفس الـ API).
